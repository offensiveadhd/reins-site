# Showcase

> Apps, agents and implementations that use Reins. The list is empty so far, and this page says how to get on it.

## Nothing here yet

Reins is at version 0.2 and this list is empty: no entry has been submitted yet.

What exists today is in the repository:

- **Brew Kiosk**, the demo app in [`examples/kiosk`](https://github.com/offensiveadhd/reins/tree/main/examples/kiosk), with a scripted agent and an in-tab example. See the [Quickstart](../start/quickstart.md).
- **The [playground](../../playground.html)** on this site, which runs Brew Kiosk's logic in the in-tab shape.

If you build something with Reins, it can be the first entry.

## What belongs here

- **Apps** that are drivable through Reins: a page that embeds the driver.
- **Agents and harnesses** that drive pages through it.
- **Implementations** of the protocol in another language or runtime, and tools built around it.

## How to get listed

Open a pull request that adds an entry to this page: the file is `site/wiki/community/showcase.md`, and the "Edit this page on GitHub" link below leads to it. An entry says:

- the name of the project and where to find it;
- what it is: an app, an agent, an implementation or a tool;
- which shape it uses, with a hub or in the tab, and which protocol version;
- for an implementation, which roles it implements and whether it passes the [test vectors](../implementers/test-vectors.md).

Keep it to a few factual lines. The maintainers of the repository decide what is merged. A listing describes what a project says about itself; it is not an endorsement, and nobody has verified it unless the entry says so.

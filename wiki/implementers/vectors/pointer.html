Binary pointer frames

Test vectors: Binary pointer frames. Shown here as it is in conformance/vectors/pointer.json.

Generated at build time from conformance/vectors/pointer.json.

Protocol 0.1. Covers: SPEC.md section 11, "Pointer stream" (layout table and encoding of fractions).

Download pointer.json: the file itself, as the conformance suite reads it.

How to use it #

Encode frame and compare with hex; decode hex and compare with frame; clamp and rounding cases check the encoding of fractions and dt; invalid must be refused.

Layout #

Text
offset 0  u8   kind  0x01 (BIN_POINTER)
offset 1  u8   flags 0x01 PTR_FLAG_DROPPABLE, 0x02 PTR_FLAG_END
offset 2  u16  ch
offset 4  u32  seq of the first point
offset 8  u16  n, number of points
offset 10 n x { u16 x, u16 y, u16 dt }, all little-endian
a fraction f is sent as round(f x 65535) after clamping to 0..1 (non-finite as 0), halves up; read back as u / 65535; dt is rounded and clamped to 0..65535

Notes #

The layout and the rounding rule are in SPEC 11. cases use exact multiples of 1/65535; rounding checks fractions between two steps; clamp checks out-of-range values; invalid frames are not pointer frames.

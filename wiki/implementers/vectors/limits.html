Default limits and fixed numbers

Test vectors: Default limits and fixed numbers. Shown here as it is in conformance/vectors/limits.json.

Generated at build time from conformance/vectors/limits.json.

Protocol 0.2. Covers: SPEC.md sections 3 to 13.

Download limits.json: the file itself, as the conformance suite reads it.

How to use it #

The complete error code list of SPEC section 6, and numeric limits the spec states.

Notes #

Only numbers the spec states. Lengths in characters are UTF-16 code units unless the key says code points.

Reins

An open protocol and a reference implementation. Protocol 0.2, package 0.2.0; this version still speaks 0.1 with a peer that knows no other. The wire format may change before 1.0.

Handshake authentication proofs

Test vectors: Handshake authentication proofs. Shown here as it is in conformance/vectors/auth.json.

Generated at build time from conformance/vectors/auth.json.

Protocol 0.1. Covers: SPEC.md section 5.

Download auth.json: the file itself, as the conformance suite reads it.

How to use it #

For each case compute HMAC-SHA256(key, peerInput) and HMAC-SHA256(key, hubInput) over UTF-8 bytes, base64url; compare with peerProof and hubProof. The third case has a non-ASCII kid.

Formula #

Text
proof = b64url(HMAC-SHA256(key, context + "\n" + role + "\n" + kid + "\n" + nonce + "\n" + cnonce)); context "reins.v1.auth" for hello.auth.proof, "reins.v1.hub" for welcome.proof

Notes #

b64url is RFC 4648 base64url without padding. The HMAC key is the UTF-8 bytes of the secret and the message the UTF-8 bytes of the string, as SPEC 5 states; the third case has a non-ASCII kid. Nonces and keys here are fixed stand-ins for the random values.
